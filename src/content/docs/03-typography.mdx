# Типографика

## Шрифт документа

Основной шрифт: Courier Prime, лицензия SIL Open Font License 1.1. Встраивается в бинарник без ограничений. Поддерживает кириллицу. Четыре начертания: Regular, Bold, Italic, Bold Italic.

Альтернатива: JetBrains Mono, лицензия Apache License 2.0. Смена шрифта документа применяется без пересборки интерфейса.

Courier Prime шире большинства моно-шрифтов, спроектированных для кода. Ширина колонки документа рассчитана с учётом этого, см. раздел «Ширина колонки».

## Шрифт интерфейса

Для тулбара, боковой панели, диалогов и статус-бара используется Inter, лицензия SIL Open Font License 1.1. Используются начертания Regular и Medium. Bold в интерфейсе не используется.

## Ширина колонки

Документ ограничен по ширине и центрирован. 65-75 символов Courier Prime на строку, около 620px на стандартном DPI.
