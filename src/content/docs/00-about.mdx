# Что такое Mauna

Лицензия CC BY-SA 4.0

Mauna: дизайн-система для кроссплатформенных писательских интерфейсов. Токены и компоненты рассчитаны на минимальную площадь хрома: панели, тулбары и боковые меню занимают на экране минимум места, необходимого для текущей задачи.
