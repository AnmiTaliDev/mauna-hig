# Пространство и сетка

8-точечная сетка.

<SpacingGrid />

```
mauna.space.xs   4px
mauna.space.sm   8px
mauna.space.md   12px
mauna.space.lg   16px
mauna.space.xl   24px
mauna.space.2xl  32px
mauna.space.3xl  48px
```

Скругления:

```
mauna.radius.sm  4px   мелкие элементы: чипы, точки, теги
mauna.radius.lg  8px   карточки, попапы, диалоги
```

Значения больше 8px не используются.
