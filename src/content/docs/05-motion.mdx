# Движение

Три длительности. Пружины и bounce-эффекты не используются.

```
mauna.motion.fast   120ms  ease-out       hover, переключатели
mauna.motion.base   200ms  ease-in-out    появление панелей, попапов
mauna.motion.slow   320ms  ease-in-out    переход между режимами
```

Анимация используется для элементов, требующих объяснения появления на экране. Для остальных случаев анимация не применяется.
