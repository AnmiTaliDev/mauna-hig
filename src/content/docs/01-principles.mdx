# Принципы

**Приоритет текста.** Панели активны, пока используются. При переключении внимания на письмо контраст панелей снижается, насыщенность снижается, анимация отсутствует.

**Плоские поверхности.** Заливки плоские. Линии толщиной 0.5px. Без градиентов. Без мягких теней, кроме одного исключения в разделе «Компоненты».

**Один акцентный цвет.** Акцентный цвет применяется к курсору, активному выделению и одной кнопке действия за раз. Остальные элементы используют оттенки серого и охры.

**Раздельная типографика.** Документ набран моноширинным шрифтом. Интерфейс набран гуманистическим sans. Различие визуально считывается без чтения подписей.
