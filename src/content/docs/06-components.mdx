# Компоненты

Компонентная система реализована как набор функций отрисовки поверх собственного canvas, не как дерево виджетов.

<ComponentDemo />

## Тулбар

Высота 40px. Фон `mauna.bg.chrome`. Нижняя граница `mauna.line`. Иконки без подписей, стиль outline. В фокус-режиме тулбар скрывается через `mauna.motion.slow` сдвигом вверх за пределы холста.

## Боковая панель

Список сцен и заголовков документа. Сворачивается в 0px. Ширина по умолчанию: от 170 до 200px, фиксированная. При изменении размера окна растягивается только холст документа.

Активный пункт списка: заливка `mauna.bg.canvas` на фоне `mauna.bg.chrome`, без рамки. Акцентная заливка на пункт списка не используется.

## Холст документа

Центрированная колонка фиксированной ширины. Поля учитываются при расчёте макета страницы.

Курсор: вертикальная линия толщиной 2px, цвет `mauna.accent`, период мигания 530 мс.

## Статус-бар

Высота 28px. Текст 12px, цвет `mauna.text.secondary`. Содержимое: счётчик слов, номер страницы. Интерактивные элементы сложнее ссылки размещаются в тулбаре.

## Попап и командная палитра

Появление по `mauna.motion.base`. Фон `mauna.bg.chrome`, радиус `mauna.radius.lg`. Тень: `0 2px 8px rgba(0,0,0,0.08)` в светлой теме, вдвое слабее в тёмной. Это единственный компонент системы, использующий тень.
