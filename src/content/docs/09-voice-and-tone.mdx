# Голос и тон текста интерфейса

Подписи кнопок: повелительное наклонение, короткая форма. Пример: «Сохранить».

Сообщения об ошибках: указание проблемы и действия, без восклицательных знаков. Пример: «Не удалось открыть файл. Проверьте путь».

Формулировки полей ввода: прямое указание, без вводных конструкций вежливости. Пример: «Введите название документа».
