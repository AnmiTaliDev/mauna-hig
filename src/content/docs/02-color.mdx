# Цвет

Две базовые темы: светлая и тёмная. Холодный нейтральный фон, один акцентный цвет, минимальный контраст между соседними уровнями поверхности.

Контрасты тёмной темы пересчитаны отдельно от светлой. `mauna.text.secondary` использует близкие, но не идентичные значения между темами: холодный серый требует небольшой коррекции светлоты для сохранения контраста AA на каждом фоне отдельно. В обеих темах `mauna.text.secondary` даёт не меньше 4.5 к 1 и к `mauna.bg.canvas`, и к `mauna.bg.chrome`.

`mauna.text.on-accent`: цвет текста поверх акцентной заливки. Используется в выделении и на кнопке действия.

## Кастомизация акцента

`mauna.accent` это токен. Значение по умолчанию: стальной синий. Пользователь может задать любой hex.

Один hex не даёт контраст 4.5 к 1 одновременно на светлом и тёмном фоне. Поэтому каждый проверенный вариант задан парой: значение для светлых тем и значение для тёмных. Каждое значение даёт не меньше 4.5 к 1 к `mauna.bg.canvas` и `mauna.bg.chrome` всех пресетов своей яркости. `mauna.text.on-accent` даёт не меньше 4.5 к 1 на каждом значении.

| Название | Светлые темы | Тёмные темы |
|---|---|---|
| Стальной синий (по умолчанию) | `#36669B` | `#5B8FC7` |
| Графит | `#5A5D66` | `#858994` |
| Холодный тил | `#226F64` | `#2F9A8A` |
| Индиго | `#5156C4` | `#7F82D3` |
