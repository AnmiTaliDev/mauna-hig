# Цвет

Две базовые темы: светлая и тёмная. Холодный нейтральный фон, один акцентный цвет, минимальный контраст между соседними уровнями поверхности.

Контрасты тёмной темы пересчитаны отдельно от светлой. `mauna.text.secondary` использует близкие, но не идентичные значения между темами: холодный серый требует небольшой коррекции светлоты для сохранения контраста AA на каждом фоне отдельно.

## Кастомизация акцента

`mauna.accent` это токен. Значение по умолчанию: стальной синий. Пользователь может задать любой hex. Ниже перечислены альтернативы с проверенным контрастом AA на обеих базовых темах.

| Название | Hex |
|---|---|
| Стальной синий (по умолчанию) | `#3B6FA8` |
| Графит | `#5A5D66` |
| Холодный тил | `#2B8C7E` |
| Индиго | `#5B5FC7` |
